# Python como lenguaje del programa

El programa se escribe en Python, aunque es una aplicación de escritorio solo para Windows, donde C#/.NET habría sido la opción más nativa. Elegimos Python porque la eliminación del fondo con IA local y el procesamiento de imagen (separación tonal, tramado) dependen de librerías gratuitas que existen sobre todo en Python; en .NET esa parte habría sido mucho más difícil. Para entregarlo como programa de Windows se empaqueta en un `.exe`.
